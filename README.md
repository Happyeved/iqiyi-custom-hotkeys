# iqiyi-custom-hotkeys

爱奇艺网页版自定义快捷键脚本，提供独立设置弹窗，支持手动保存快捷键、长按倍速播放和视频内加速提示。

- **当前版本：** 1.0.0
- **使用环境：** 爱奇艺网页版 + Tampermonkey（油猴）
- **脚本名称：** 爱奇艺快捷键设置（手动保存）

## 快速安装

👉 **[点击安装或更新 v1.0.0](https://raw.githubusercontent.com/Happyeved/iqiyi-custom-hotkeys/main/iqiyi-custom-hotkeys.user.js)**

1. 在浏览器中安装并启用 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 点击上方安装链接。
3. 在油猴安装页面确认脚本名称为「爱奇艺快捷键设置（手动保存）」、版本为 **1.0.0**，点击安装或更新。
4. 刷新已经打开的爱奇艺视频页面，使脚本生效。

以后更新脚本时，再次打开上方链接，按油猴提示确认并刷新视频页面。

## 脚本功能

- 自定义播放、暂停、快进、快退、音量、上一集、下一集、全屏、静音和重播等快捷键。
- 支持单键和组合键，点击输入框后直接按键录入。
- 提供独立设置弹窗，使用浏览器默认外观。
- **仅点击「保存」后才应用并保存设置**；修改、清空和恢复默认均不会自动保存。
- 长按加速跟随爱奇艺菜单中的「长按倍速」设置。
- 加速时在视频上方显示实际倍数，例如「2倍快速播放中」；支持播放器全屏显示。
- 松开加速键或切出页面后恢复原倍速，并隐藏加速提示。
- 检查快捷键冲突；快进与长按倍速可以共用一个键。
- 在输入框或可编辑区域中打字时，不触发播放器快捷键。

## 默认快捷键

下表为新安装时的默认设置；已有保存设置的用户继续使用自己的配置。

| 功能 | 默认快捷键 |
| --- | --- |
| 播放 / 暂停 | 空格 |
| 快退 5 秒 | ← |
| 快进 5 秒（单按） | → |
| 音量增加 5% | ↑ |
| 音量降低 5% | ↓ |
| 上一集 | Shift + P |
| 下一集 | Shift + N |
| 进入 / 退出全屏 | F |
| 静音 / 取消静音 | M |
| 从头重播 | 0 |
| 退出全屏 | Esc |
| 长按倍速 | 长按 → |

## 自定义快捷键

1. 打开爱奇艺视频页面。
2. 点击页面右下角的「快捷键设置」，或从油猴菜单选择「爱奇艺：快捷键设置」。
3. 点击要修改的快捷键输入框，直接按下单键或组合键。
4. 按需要使用「清空」或「恢复默认」。
5. 点击「保存」后，新设置才会应用并保存。

点击「取消」或直接关闭弹窗，会放弃本次未保存的修改。设置只保存在当前浏览器的脚本存储中。

### 按键说明

- 「清空」表示取消该项的脚本绑定。
- 快进和长按倍速可绑定同一个键；其他功能存在重复绑定时，需要先解决冲突才能保存。
- 未绑定到其他功能的原生 ↑ / ↓ 仍可用于网页音量控制。
- Esc 仍保留浏览器退出全屏的行为；浏览器或系统占用的快捷键可能无法使用。

## 长按倍速的使用方法

1. 在爱奇艺播放器的倍速菜单中，打开「长按倍速」并选择所需倍数，例如 **2.0X**。
2. 按住脚本绑定的长按倍速键，默认是 **→**。
3. 持续按住超过约 **350 毫秒**后进入加速，视频上方显示「2倍快速播放中」等提示。
4. 松开按键后，恢复长按前的播放倍速，提示立即消失。

当快进与长按倍速共用一个键时，短按快进 5 秒，长按进入加速。长按结束时不会再额外快进。

如果倍速设置未能同步，可悬停展开一次爱奇艺的倍速菜单，然后再次长按。

## 安装链接只显示代码怎么办

可以使用油猴手动安装：

1. 复制安装链接页面中的全部脚本代码。
2. 打开油猴，选择「添加新脚本」。
3. 用复制的代码替换编辑器中的默认内容，并保存。
4. 确认脚本已启用，再刷新爱奇艺视频页面。

安装方式也可参考 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?locale=zh&q=Q102)。
